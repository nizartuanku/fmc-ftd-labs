# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Network discovery shows correct OS and services for the protected hosts.
- [ ] Adaptive profiles are enabled; Enable Profile Updates is selected where needed.
- [ ] The Networks field covers the protected subnets.
- [ ] The inline versus passive approach is chosen (inline normalization or profile updates).
- [ ] Recommended-rule changes were reviewed before deployment.
- [ ] Events after deployment match the expected host context.
