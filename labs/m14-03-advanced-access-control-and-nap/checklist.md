# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The default NAP and the pre-identification intrusion policy are set deliberately.
- [ ] Network analysis rules match the intended networks or zones.
- [ ] The inspection engine version matches the settings you edited.
- [ ] A policy comparison or report was reviewed before deployment.
- [ ] Deployment history shows the new revision deployed to the device.
