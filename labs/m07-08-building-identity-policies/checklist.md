# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The identity policy is associated with the access control policy and deployed.
- [ ] Identity rules use IP networks, not FQDN objects.
- [ ] Connection events show user names for inside users and for portal users.
- [ ] Rules exist for the special identities (Unknown, Failed Authentication, Guest).
- [ ] The realm downloads users and groups without mismatches.
