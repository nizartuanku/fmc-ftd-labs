# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The example matches the target hardware model.
- [ ] Preview Config shows the expected commands and variable values.
- [ ] The deployment transcript shows no rejected commands.
- [ ] `show running-config` on the device contains the deployed lines.
- [ ] No feature is configured both in FlexConfig and in the GUI.
