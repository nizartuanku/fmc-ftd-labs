# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The engine version was checked.
- [ ] Flag names match exactly between the set and isset rules.
- [ ] The setting rule uses noalert if it should not generate its own event.
- [ ] The sequence was tested both ways: with and without the first step.
- [ ] Any file policy with Inspect Archives has at least one active file rule.
- [ ] The deployment preview was reviewed before deploying.
