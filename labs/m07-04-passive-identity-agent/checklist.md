# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The agent shows as connected in the management center.
- [ ] Logons on the lab VM produce user-to-IP mappings (user names in connection events).
- [ ] The realm downloads the groups referenced in access rules (no realm or user mismatches).
- [ ] The secondary agent takes over when the primary is unavailable.
- [ ] The agent host meets the security requirements in the guide.
