# Troubleshooting

| Symptom | Likely cause | What to check |
|---|---|---|
| No connection events | Logging is off or only at beginning of connection | Enable end-of-connection logging |
| No intrusion event | The traffic was blocked earlier or the rule is disabled | Check Security Intelligence events and the intrusion policy |
| Host missing from the network map | Network discovery does not cover that network | Check the network discovery policy |

---
*Always confirm behavior against the guide for your exact FMC/FTD version.*
