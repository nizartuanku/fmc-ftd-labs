# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The device runs a supported release with the Snort 3 engine.
- [ ] Threat Detection started in Detection mode and was tuned before enabling Prevention.
- [ ] Internal scanners and busy infrastructure hosts are on the ignore and exclude lists.
- [ ] Port scan events appear in the management center for test scans.
- [ ] The team knows the CLI steps to release a falsely blocked host.
