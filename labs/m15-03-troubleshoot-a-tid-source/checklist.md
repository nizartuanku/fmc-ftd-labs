# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Every source shows a healthy, recent update.
- [ ] Source SSL Settings match the server's certificate requirements.
- [ ] `sftunnel-status-brief` shows the management connection up on each device.
- [ ] Element status shows devices receiving published observables.
- [ ] Duplicated indicators are reduced to one published copy.
- [ ] Incidents show the expected action (Monitored or Blocked) and match the connection events.
