# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Source status is healthy and updating.
- [ ] The observable action was confirmed, not assumed from the indicator or source.
- [ ] Publishing is not paused for the indicator.
- [ ] The address is not on the Security Intelligence Do Not Block list.
- [ ] Traffic is allowed, not trusted, so TID can see it.
- [ ] The incident's Action Taken matches the connection and Security Intelligence events.
