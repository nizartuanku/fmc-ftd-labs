# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The feature is not managed by the GUI in your management center version.
- [ ] The command is supported by your threat defense software version.
- [ ] The FlexConfig policy targets only the intended devices.
- [ ] Preview Config shows the expected lines.
- [ ] The deployment transcript shows no rejected commands.
- [ ] `show running-config` on the device shows the deployed command.
