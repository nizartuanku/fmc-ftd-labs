# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The default action is set intentionally and was reviewed before deployment.
- [ ] Required licenses are present on every target device.
- [ ] Base Mandatory rules appear above descendant rules in the rule view.
- [ ] `packet-tracer` shows the expected rule matching, not the default action.
- [ ] `show access-control-config` shows the deployed policy name and default action.
