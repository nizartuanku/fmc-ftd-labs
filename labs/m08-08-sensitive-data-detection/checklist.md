# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Engine version and licensing were checked.
- [ ] Custom patterns use the documented simple syntax, not PCRE.
- [ ] Ports and application protocols cover the paths data could leave by.
- [ ] FTP requirements are met if FTP must be inspected.
- [ ] Test strings generate events; the rule is set to drop only after review.
