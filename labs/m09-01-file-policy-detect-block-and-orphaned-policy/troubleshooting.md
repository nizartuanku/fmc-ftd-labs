# Troubleshooting

| Symptom | Likely cause | What to check |
|---|---|---|
| No file events appear | The policy is not attached to an allow rule, or was not deployed | Attach it to an Allow rule and deploy |
| Malware actions are unavailable | The Malware Defense license is missing | Assign the license to the device |
| Archive inspection does nothing | The file policy has no file rules | Add at least one file rule |

---
*Always confirm behavior against the guide for your exact FMC/FTD version.*
