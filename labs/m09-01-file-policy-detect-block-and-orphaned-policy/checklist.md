# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Required licenses (IPS; Malware Defense for malware actions) are assigned to the device.
- [ ] The file policy contains at least one active rule.
- [ ] The file policy is attached to the intended access control rule or rules.
- [ ] The configuration was deployed to the managed device.
- [ ] File and malware events appear for test traffic.
- [ ] Connection events for the test traffic show the access control rule you edited.
