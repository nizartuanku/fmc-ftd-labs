# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The AMP cloud connection shows as connected.
- [ ] Malware Defense is licensed on devices that use malware actions.
- [ ] File events show SHA-256 hashes and dispositions.
- [ ] Retrospective events are visible in malware events.
- [ ] Secure Malware Analytics association is in place if you need detailed reports.
- [ ] Endpoint-based events appear if Secure Endpoint is integrated.
