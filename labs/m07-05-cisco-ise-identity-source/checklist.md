# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] The ISE identity source shows a successful connection (the test passes).
- [ ] ISE SGTs appear as choices in the access rule editor.
- [ ] Connection events show user names and SGTs for lab clients.
- [ ] Destination SGT rules are used only where the SXP topic is enabled.
- [ ] No realm or user mismatches between ISE and the management center realm.
