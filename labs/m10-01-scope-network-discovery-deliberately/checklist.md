# Verification checklist

Work through this after the test steps. Do not assume it works: confirm each item.

- [ ] Monitored networks match the subnets you are responsible for.
- [ ] Port exclusions cover only high-volume, low-value traffic.
- [ ] Discovery is limited to the intended zones.
- [ ] Policy changes are deployed in a maintenance window.
- [ ] The network map shows the expected hosts after deployment.
