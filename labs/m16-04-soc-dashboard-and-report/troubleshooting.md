# Troubleshooting

| Symptom | Likely cause | What to check |
|---|---|---|
| Widgets are empty | No events in the time range or logging is off | Widen the time range and check rule logging |
| A widget is shaded red | The widget query is too expensive | Remove or narrow the widget |
| Report cannot be emailed | No mail relay host configured | Configure the mail relay host first |

---
*Always confirm behavior against the guide for your exact FMC/FTD version.*
